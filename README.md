# WPF_TodoApp 📝
Простое приложение списка задач на C# с использованием WPF.

## Скачать
Скачай последнюю версию в разделе [Releases](https://github.com/Roma4ja/WPF_TodoApp/releases) — скачай архив, распакуй и запусти `setup.exe`

## Функционал
- Добавление задач
- Удаление выбранной задачи
- Простой и понятный интерфейс

## Управление
- Введи задачу в поле ввода
- Нажми **"Добавить"** — задача появится в списке
- Выбери задачу и нажми **"Удалить выбранное"**

## Структура проекта
- `MainWindow.xaml` — разметка интерфейса
- `MainWindow.xaml.cs` — логика приложения

## Технологии
- Язык: C#
- Платформа: .NET Framework
- Тип: WPF Desktop приложение
- IDE: Visual Studio

## Системные требования
- Windows 10/11 x64
- Установка не требуется
